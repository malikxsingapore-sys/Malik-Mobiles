# iPhone Store Website

A responsive front-end demo store for iPhone models.

Files:
- index.html — website structure
- style.css — responsive design
- script.js — products, search, filters and cart

Before publishing:
1. Replace the WhatsApp number `923000000000` in index.html and script.js.
2. Replace demo prices with your actual prices.
3. Add your own product photos if desired.
4. Connect a real payment gateway/backend if you want online payments.

This is a front-end demo and does not process real payments by itself.
